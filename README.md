# 🌿 GlassGarden (باغ شیشه‌ای هوشمند)

پروژه **GlassGarden** یک سیستم اینترنت اشیا (IoT) برای پایش و کنترل یک باغ شیشه‌ای (تراریوم/گلخانه خانگی) است. این سیستم با استفاده از میکروکنترلر قدرتمند **ESP32** و پلتفرم **Blynk**، امکان پایش و مدیریت کامل محیط گیاهان را از راه دور فراهم می‌کند.

## ✨ ویژگی‌ها
- 🌡️ **پایش لحظه‌ای:** اندازه‌گیری دقیق دما و رطوبت محیط (سنسور DHT)
- 📱 **کنترل از راه دور:** مدیریت سیستم از طریق اپلیکیشن موبایل Blynk
- ⚡ **پردازش سریع:** مبتنی بر تراشه ESP32 دارای وای‌فای داخلی
- 📊 **معماری یکپارچه:** ترکیب بهینه طراحی سازه، سخت‌افزار و نرم‌افزار

## 🛠️ نیازمندی‌های سخت‌افزاری
- برد توسعه ESP32 (مدل `esp32dev`)
- سنسور دما و رطوبت (DHT11 یا DHT22)
- ماژول رله (جهت کنترل روشنایی، پمپ آب یا تهویه)
- منبع تغذیه پایدار
- محفظه شیشه‌ای و تجهیزات باغبانی

## 💻 نیازمندی‌های نرم‌افزاری
- محیط توسعه PlatformIO (توصیه شده) یا Arduino IDE
- فریم‌ورک Arduino
- کتابخانه `blynkkk/Blynk`
- کتابخانه `adafruit/DHT sensor library`
- حساب کاربری و اپلیکیشن موبایل Blynk
